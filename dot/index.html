ドット絵エディタ DOT

自由サイズ・部位ID付きSVG・インポート・色数削減対応

キャンバスサイズ

1〜1024。既存の絵は左上基準で保持されます。

インポート

画像を選ぶと元サイズが表示されます

ツール

部位（SVGグループID）

キャラの「目」「体」など部位ごとに id を付けます。部位ツールで塗るか、描画時に割り当て。

    カラー

    使用色数: 0

    色数の削減・近似

    パレット色だけを使い、全ピクセルを最も近い色に置き換えます。

    表示

    エクスポート

    部位グループがあればキャラの目・体などを個別に操作できます。

    ショートカット: Ctrl+S
