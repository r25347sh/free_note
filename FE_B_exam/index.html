記述形式説明

              
○手続名又は関数名手続又は関数を宣言する

              
型名: 変数名変数を宣言する

              
/* 注釈 */ // 注釈注釈を記述する

              
変数名 ← 式変数に式の値を代入する

              
手続名(引数, …)手続又は関数を呼び出す

              
if (条件式) … elseif … else … endif選択処理

              
while (条件式) … endwhile前判定繰返し

              
do … while (条件式)後判定繰返し

              
for (制御記述) … endfor繰返し処理
