🔒 Lock System Demo

free_note / lock モジュールの動作確認ページ

使い方

  1. 右上の 🔒 ボタン を押すとロックが開始されます。
  2. ロック中は画面に 🔒 と LOCKED だけが表示されます。
  3. ロック中にマウスを動かしたりクリックすると、アラート音がループ再生されます。
  4. 解除・アラート停止は、決められたキー入力シーケンスで行います（画面上には一切表示されません）。

音声ファイルについて

現在は ./alert.mp3 を参照するようになっています。

alert.mp3 をこの lock/ フォルダに置いてください。
別のパスを使いたい場合は、下のスクリプト内の audioSrc を変更してください。
